III. Informationen zur Datenverarbeitung

Aus technischen Gründen, insbesondere zur Gewährleistung eines sicheren und stabilen Betriebs dieser Website, werden beim Aufruf der Website durch den Internetbrowser des Nutzers technische Daten an den für die Bereitstellung der Website eingesetzten Dienstleister übermittelt. Die Website wird über GitHub Pages, einen Dienst der GitHub, Inc., bereitgestellt. Dabei können insbesondere folgende Daten verarbeitet werden:

  • IP-Adresse,
  • Datum und Uhrzeit des Zugriffs,
  • aufgerufene Seiten und Dateien,
  • Informationen zum verwendeten Internetbrowser,
  • Informationen zum verwendeten Betriebssystem,
  • Referrer-URL, sofern diese vom Browser übermittelt wird,
  • technische Informationen über den erfolgreichen oder fehlerhaften Abruf von Inhalten.

Diese Daten werden verarbeitet, um die Website technisch bereitzustellen sowie deren Stabilität und Sicherheit zu gewährleisten und missbräuchliche Zugriffe erkennen und abwehren zu können. Die Verarbeitung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Mein berechtigtes Interesse liegt in der sicheren, stabilen und funktionsfähigen Bereitstellung meines Internetauftritts. Die Verarbeitung personenbezogener Daten durch GitHub erfolgt nach den eigenen Datenschutzbestimmungen von GitHub. Weitere Informationen zur Datenverarbeitung durch GitHub finden Sie in der Datenschutzbestimmung von GitHub. Die entsprechenden datenschutzrechtlichen Voraussetzungen für Drittlandübermittlungen nach Art. 44 ff. DSGVO werden von GitHub nach eigenen Angaben berücksichtigt.
